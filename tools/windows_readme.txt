Winter War: Summa - Windows version (test build)

1. Unzip this folder anywhere (for example the Desktop). Keep the .exe and the .pck together.
2. Double-click WinterWarSumma.exe.
   If Windows says "Windows protected your PC": click "More info", then "Run anyway".
   (The game is not signed by a company, so Windows warns about every new program like this.)
3. The first time you host or join, Windows Firewall asks about the game:
   tick "Private networks" and click "Allow".

Playing together on the same home network:
- One player: main menu -> Host Co-op.
- The other: main menu -> Join Co-op, type the host computer's address in "Host address" and click Connect
  (for example 192.168.1.23 - the host finds it under Settings -> Network & internet -> Wi-Fi/Ethernet -> IPv4 address).
- Join before the host starts the battle.
- Both computers must have exactly the same version of the game.
